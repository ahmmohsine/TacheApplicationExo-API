# [ Web API REST .NET / Exercice] — Web API CQRS & Scalar

> Projet réalisé dans le cadre du cours de [Web Api].

---

## Objectif du TP

Mise en place d'une Web API REST .NET appliquant le pattern **CQRS** pour la séparation des commandes et des requêtes, testable via **Scalar**.

---

## 🛠 Stack Technique & Patterns

* **Framework :** .NET 10 (Web API)
* **Architecture :** Clean Architecture / CQRS (Command Query Responsibility Segregation)
* **ORM & BDD :** Entity Framework Core (SQL Server)
* **Validation :** DataAnnotations / FluentValidation
